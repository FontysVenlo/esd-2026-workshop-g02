# Northstar Supply field workshop

The active Chaos Engineering workshop is in [field-workshop](field-workshop/README.md). The previous guided workshop has been retired.

For a complete participant walkthrough, key commands, monitoring queries, and a submission checklist, see the [assignment cheatsheet](CHEATSHEET.md).

Distribute the cross-platform ZIP generated by `package-workshop.ps1`. Extract it fully, start Docker Desktop, then double-click **start.bat** on Windows or **start.command** on Mac from the extracted folder. Do not run a launcher from inside a ZIP preview. Use **stop.bat** on Windows or **stop.command** on Mac to stop the containers. No terminal or IDE is needed to start; the overview opens at <http://localhost:8088>.

With Docker Desktop running, start everything from the repository root with one command:

```powershell
.\start.bat
```

On Mac, run `bash ./start.command`. Both commands build and start the full Docker stack, including light traffic, then open the workshop overview, Storefront, Network Faults console, Grafana dashboard, and Prometheus in your default browser. The launchers inside the ZIP open the same five pages. Run the command again whenever you want to start the stack and reopen the pages.

Stop everything with `.\stop.bat` on Windows or `bash ./stop.command` on Mac. The same start and stop files work from the repository root and from the extracted ZIP.

All workshop services run in Docker; participants do not need Node.js, npm packages, or an IDE. Docker Desktop is still required, and the first start downloads the container images. Later starts reuse the cached images and build layers. The launchers wait for HTTP readiness before opening the pages; Grafana needs a few additional seconds to collect its first metrics. The workshop ZIP contains the application and configuration, not the container images.

All four challenges can be completed in the browser. In [Network Faults](http://localhost:8089), use **Fault injection** to create the problem and **Fallbacks & timeouts** to apply or reset the shop's response immediately. The same controls work on Windows and Mac. **Info & commands** has a platform selector for optional PowerShell or Mac Terminal examples.

The [workshop README](field-workshop/README.md) has the full setup, tools, and challenge instructions.
