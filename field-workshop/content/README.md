# Workshop page text

Edit `home.json` for Home and `challenge-1.json` through `challenge-4.json` for the assignments. Each challenge’s `tasks` array supplies the instructions under “Your tasks”. Run `npm start` for automatic page refresh on save. The regular start launcher requires a rebuild after editing.

The Storefront, Network Faults and Tools JSON files are reference copies. See the [page editing guide](../README.md#edit-the-website-text) for their active source files.
