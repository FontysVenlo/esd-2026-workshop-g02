# Workshop page text

Edit `home.json` for Home and `challenge-1.json` through `challenge-4.json` for the assignments. Each challenge’s `tasks` array supplies the instructions under “Your tasks”. Run `npm start` for automatic page refresh on save. The regular start launcher requires a rebuild after editing.

Edit `storefront.json` for Storefront labels, product names and catalog text. The optional `catalog.eyebrow` and `catalog.description` lines disappear when omitted. Edit `network-faults.json` for the fault console (including `faultConsolePage.info_commands` for its Info tab). Edit `tools.json` for the command reference. Each page owns its wording, including template placeholders for measured or selected values.

Entries within each page section follow their display order. Status and error messages follow the main content. Each formatted paragraph is one entry. In those paragraphs, use **bold**, backticks for code, and [link text](https://example.com) for links. Keep runtime placeholders such as {milliseconds} intact.
