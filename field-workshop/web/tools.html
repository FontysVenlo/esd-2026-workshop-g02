Commands

Run these from the extracted workshop folder: PowerShell on Windows or Terminal on Mac. Use the Network Faults console for graphical fault controls.

Windows · PowerShell

Start and check

docker compose up --build -d
docker compose --profile load up -d loadgen
docker compose ps

Grafana · Prometheus targets

$proxyApi = 'http://localhost:8478'
$ua = 'field-workshop/1.0'
Invoke-RestMethod "$proxyApi/proxies" -UserAgent $ua

Inventory latency

$fault = @{ name='inventory-lag'; type='latency'; stream='downstream'; attributes=@{latency=1500; jitter=0} } | ConvertTo-Json -Depth 4
Invoke-RestMethod -Method Post -Uri "$proxyApi/proxies/inventory/toxics" -ContentType 'application/json' -Body $fault -UserAgent $ua

Remove it:

Invoke-RestMethod -Method Delete -Uri "$proxyApi/proxies/inventory/toxics/inventory-lag" -UserAgent $ua

Example mitigation:

$env:INVENTORY_TIMEOUT_MS = '400'
$env:INVENTORY_FALLBACK = 'true'
docker compose up -d --force-recreate storefront

Shipping outage

Invoke-RestMethod -Method Post -Uri "$proxyApi/proxies/shipping" -ContentType 'application/json' -Body '{"enabled":false}' -UserAgent $ua
Invoke-RestMethod -Method Post -Uri "$proxyApi/proxies/shipping" -ContentType 'application/json' -Body '{"enabled":true}' -UserAgent $ua

Example mitigation:

$env:SHIPPING_FALLBACK = 'true'
docker compose up -d --force-recreate storefront

Restore defaults

Remove-Item Env:INVENTORY_TIMEOUT_MS,Env:INVENTORY_FALLBACK,Env:SHIPPING_TIMEOUT_MS,Env:SHIPPING_FALLBACK -ErrorAction SilentlyContinue
docker compose up -d --force-recreate storefront

Clear faults in the console, or restart the stack with docker compose down then the start commands above.

Mac · Terminal

Open Terminal in the extracted folder. Docker Desktop must be running. Faults can be applied and cleared in Network Faults.

Inventory timeout and fallback

INVENTORY_TIMEOUT_MS=400 INVENTORY_FALLBACK=true docker compose up -d --force-recreate storefront

Shipping fallback

SHIPPING_FALLBACK=true docker compose up -d --force-recreate storefront

Restore defaults

unset INVENTORY_TIMEOUT_MS INVENTORY_FALLBACK SHIPPING_TIMEOUT_MS SHIPPING_FALLBACK
docker compose up -d --force-recreate storefront

These variables change the Storefront container when it is recreated. The Storefront never guesses stock or a shipping quote.
